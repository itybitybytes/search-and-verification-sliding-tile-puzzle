## Fixed 3x3 Verification Cases

These boards are centralized in `solver/verification_cases.py` and re-exported by `02_python_solver.py`. The blank is the internal `0`, displayed below as `_` for readability.

| Case | Board tuple | Readable board | Derivation / purpose | BFS-calculated minimum length |
|---|---|---|---|---|
| Solved puzzle | `(1, 2, 3, 4, 5, 6, 7, 8, 0)` | `1 2 3 / 4 5 6 / 7 8 _` | Required lower-right blank goal | `0` |
| Exactly one move away | `(1, 2, 3, 4, 5, 6, 7, 0, 8)` | `1 2 3 / 4 5 6 / 7 _ 8` | Legal blank-move scramble from goal: `LEFT`; solving move is `RIGHT` | `1` |
| Several moves away | `(1, 2, 3, 0, 4, 6, 7, 5, 8)` | `1 2 3 / _ 4 6 / 7 5 8` | Legal blank-move scramble from goal: `LEFT`, `UP`, `LEFT` | `3` |
| Invalid puzzle | `(1, 2, 3, 4, 5, 6, 7, 7, 0)` | `1 2 3 / 4 5 6 / 7 7 _` | Malformed board with duplicate `7` and missing `8` | Not applicable |
| Unsolvable valid puzzle | `(1, 2, 3, 4, 5, 6, 8, 7, 0)` | `1 2 3 / 4 5 6 / 8 7 _` | Valid tile set with incorrect parity for the lower-right blank goal | Not applicable |
| Algorithm comparison puzzle | `(1, 2, 3, 7, 0, 6, 5, 4, 8)` | `1 2 3 / 7 _ 6 / 5 4 8` | Legal blank-move scramble from goal: `LEFT`, `UP`, `LEFT`, `DOWN`, `RIGHT`, `UP` | `6` |

The BFS minimum lengths above were measured with the current `breadth_first_search` implementation, then verified by `python -m unittest discover` through `tests/test_verification_cases.py`. Expanded-state counts and algorithm comparison metrics are generated by `python 03_verify_solver.py` and captured in `04_TEST_EVIDENCE.md`.

## Reviewer Comment Convention

Important grader-facing Python code should include concise anchors such as:

```python
# ASSIGNMENT REQUIREMENT R10 — BREADTH-FIRST SEARCH
# ASSIGNMENT REQUIREMENT R14 — MISPLACED TILES EXCLUDES BLANK
```

Comments should identify assignment-relevant decisions without over-commenting ordinary Python syntax.
