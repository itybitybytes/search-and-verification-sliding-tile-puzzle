## Fixed 3x3 Verification States

Goal state:

```python
(1, 2, 3,
 4, 5, 6,
 7, 8, 0)
```

The several-move and comparison states are constructed from the goal by fixed legal blank-movement sequences, so their solvability is transparent:

- Solved state: `(1, 2, 3, 4, 5, 6, 7, 8, 0)`
- One-move state: generated by `LEFT` from goal, resulting in `(1, 2, 3, 4, 5, 6, 7, 0, 8)`
- Several-move state: generated by `LEFT, UP, LEFT` from goal, resulting in `(1, 2, 3, 0, 4, 6, 7, 5, 8)`
- Invalid state: `(1, 2, 3, 4, 5, 6, 7, 7, 0)` with duplicate `7` and missing `8`
- Unsolvable valid state: `(1, 2, 3, 4, 5, 6, 8, 7, 0)`
- Comparison state: generated by `LEFT, UP, LEFT, DOWN, RIGHT, UP` from goal, resulting in `(1, 2, 3, 7, 0, 6, 5, 4, 8)`
